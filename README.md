# TextSpan for CLAP

Companion repository for **Finding Textual Explanations of CLAP Audio Encoder Attention Heads**.

Sebastian Fia · Gabriele Santini · Elisabetta Farella

**[Companion website](https://sebastianfia.github.io/clap-textspan/)**

## Availability

This repository is being prepared for release. Reproduction scripts, frozen description dictionaries and text-to-class mappings, head-explanation atlases, and result figures will be added here.

This initial version only establishes the public repository and companion-page URLs. Experiment code and reproducibility instructions are forthcoming.

## Website

The static companion page is in `docs/` and is published with GitHub Pages from the `main` branch. It does not require a separate website repository or a local build step.
